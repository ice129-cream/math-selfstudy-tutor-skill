# 在 Codex / CLI agent 场景中使用本 skill

## 这个载体的形态

Codex 这类 CLI agent 读的是工作区里的文本文件，没有 DSH 那种 skill catalog 自动登记机制。它的做法接近 `INSTALL.md` 第五节：**项目级指令文件 + 同目录 references**。 agent 会把项目级指令（常见约定名如 `AGENTS.md`，具体文件名以所用版本为准）当作常驻行为约定；正文里若写了 `references/ladder.md` 这样的相对路径，agent 能在工作区里按路径打开文件。这就给"按需打开分册"留了一条路——虽然不如 DSH 的原生调度自动，但比 GPTs / Project 那种一整段文本强。

本 skill 的全部要求只有两条：能读到 `SKILL.md` frontmatter 之下的正文，能按相对路径打开 `references/`。做到这两条，四层闭环、三张台、自检闸门、真题为母就都在。

## 安装路径（两种，选一种）

### 方式一：指令文件 + 保留目录结构

1. 把 `SKILL.md` 里 frontmatter（开头 `---` 到 `---` 那段）**以下**的正文，完整注入项目的 agent 指令文件（如 `AGENTS.md`）。frontmatter 的 `name` / `description` 是给 DSH catalog 用的，这里不需要。
2. 把整个 `skills/math-selfstudy-tutor/references/` 与 `examples/` 目录放到 agent 工作区里，保持相对路径结构不变——正文里的 `references/ladder.md`、`references/preflight.md` 等引用就是按这个相对路径去找的。直接把 `skills/math-selfstudy-tutor/` 整目录拷到工作区，指令正文放在同目录或其上级，让相对路径对得上。
3. 若 agent 版本支持自定义 skill / command 目录，把整个 `skills/math-selfstudy-tutor` 放进该目录、以 `SKILL.md` 为触发入口，效果更接近原生：命中数学陪练意图才加载。

注意：指令文件名与 skill 扫描目录随 agent 版本变化，以所用版本的文档为准。本文件不假定某个具体按钮或菜单名。

### 方式二：完整目录直接放在工作区

把仓库的 `skills/math-selfstudy-tutor/` 原样放进工作区某处，在指令文件里写一句"数学陪练任务遵循 `skills/math-selfstudy-tutor/SKILL.md`"。 agent 读到这句后自行打开该文件，再按正文索引去取对应分册。这种方式改动最小，仓库更新后同步该目录即可。

## 调用：大白话就够

CLI agent 里直接用自然语言说需求，不必造命令：

- "这道题我不会，帮我讲" → 应以闭环台起步，布置任务、先不主动给提示，绝不直接给解析。
- "我讲给你听这道中值定理题" → 进入讲题环节，倾听不打断，讲完再集中拷问。
- "帮我批改这段推导" → 进核验台，按五维查说理链条，不打√×。
- "这定理前提是什么，会变形吗" → 进探究台，先让他自己预判说理再验证。
- "卡住了" → 按四层提示梯度放提示，不给完整推导。

`/出题` `/讲题` `/批改` `/变式` `/自检` 这类斜杠文本只当**意图信号**，不是 shell 命令，不要让 agent 去执行；项目文档里也别把它们宣传成命令。

## 命令行场景的特殊提醒

CLI agent 容易滑向"把题解出来"——它擅长执行、擅长给确定答案，而本 skill 恰好要求不给答案、逼学生输出。所以每次进入数学陪练，先确认它在按三张台行事：进场有没有说"现在进 X 模式";闭环台有没有先布置任务而不是开讲；核验台有没有只查说理链条而不打√×。发现它开始写完整推导、开始连发题目，直接提醒它回到"让学生主讲"的轨道。

## 核心模式不可削弱

CLI 载体若能读到 `references/`，按需加载可以保留大半；即便 agent 版本只能读单文件、把分册压进指令正文，下列几条仍是身份本身，任何精简都不许削弱：

- **三张工作台互斥**：闭环台（默认）、核验台、探究台，按信号进唯一一张，进场明说"现在进 X 模式"，一张台内不混入另一张台的动作。
- **四层闭环以学生输出通关**：独立做题 → 做懂题 → 讲懂题 → 举一反三，层层以学生交出的结果 / 论证 / 完整主讲 / 变式说理放行，没交出就不进下一层；终点是"脱离导师也能讲清楚"，不是听懂或算出答案。
- **自检闸门**：凡导师主动出的题，发出前独立完整验算，六项全过才发，不发错题；学生自带的真题不触发。
- **不给答案、不泄底**：四层提示梯度（本质锚点 → 结构 → 缺口 → 极小片段示范），永不泄漏完整推导，不替学生写讲稿。
- **真题为母**：官方真题优先、结构性改编，不凭空造题、不拿来源不明的模拟卷当主素材。

Codex 这类 agent 弱化的是"自动按需加载"的便利，上面五条一条都松不得。
